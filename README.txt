MERIDIAN DYNAMICS WEBSITE - VERSION 1

1. Extract this ZIP anywhere on your Dell.
2. In VS Code choose File > Open Folder and select meridian-website.
3. Right-click index.html and choose Open with Live Server.
4. Edit index.html for content, style.css for design, script.js for behavior.
5. Replace the temporary MD monogram in the hero with your original logo once ready.

This is a static website. The email button opens your visitor's mail app.
Do not publish private contact details or sensitive client information.
